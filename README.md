📊 Student Report Dashboard – README
🔍 Purpose:
To monitor and analyze student academic performance, behavior, and attendance across sections, subjects, terms, and classes.

🧩 Key Metrics:
Total Students: 1000

Average Score: 49.9%

Average Attendance: 90.0%

📌 Visuals Included:
Behavior Distribution (Donut Chart):
Breakdown of behavior types (Disruptive, Helpful, Late, etc.)

Classwise Average Score (Bar Chart):
Comparison of average scores across different classes.

Subjectwise Average Score (Bar Chart):
Performance across subjects (Math, Science, English, etc.)

Termwise Average Score (Line Chart):
Score trend across terms (Term 1 to Term 3).

Student-wise Score Table:
Student details with individual scores and demographics.

🎛 Filters Available:
Section (A, B, C)

Subject (English, Geography, History, Math, Science)

Class (Dropdown selection)

Term (Select Term 1, 2, 3 or all)

🛠 Tools Used:
Power BI for data visualization and interaction
